Comment ça marche
  1. Ouvre le Riot Client (le launcher) avec le compte qui a les bons settings, puis clique sur + Enregistrer ici.
  2. Ferme le launcher (et Valorant). Laisse ValoSettings ouvert.
  3. Rouvre le Riot Client avec le nouveau compte (Valorant fermé).
  4. Dans l'onglet Profils, clique sur Appliquer →, choisis les catégories, puis Appliquer.

Une sauvegarde du compte cible est faite automatiquement avant chaque application.
